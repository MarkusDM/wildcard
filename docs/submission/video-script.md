# WILDCARD 5-Minute Demo Script

## 0:00 - 0:20

Show splash screen and lobby.

Voiceover:
WILDCARD is a 1v1 poker game on Arc. We keep deposits, locked buy-ins, and settlement on-chain, while the poker engine and magic gameplay run off-chain for speed.

## 0:20 - 0:45

Show wallet area and deposit panel.

Voiceover:
Players can deposit USDC into the platform, then lock a buy-in before entering a duel. This gives us a credible money layer without forcing every gameplay action on-chain.

## 0:45 - 1:15

Show public duel creation and private room flow.

Voiceover:
We support public matchmaking for fast 1v1 games, private room codes for friend challenges, and an agent mode so the product is always demoable even without a second player.

## 1:15 - 2:10

Enter a match and show cards, pot, and magic actions.

Voiceover:
Inside the match, the game feels like a compact duel. The server runs the poker state, hand flow, and magic effects off-chain, so the interface stays responsive and the game is actually playable.

## 2:10 - 3:15

Show the three coach buttons and request advice.

Voiceover:
Our main monetization layer is paid AI coaching. Players can ask for a best move, a risk read, or advice on when to use magic. These are not subscriptions. They are individual in-match services.

## 3:15 - 3:55

Show proof panel and payment ledger after several calls.

Voiceover:
Every paid advice call is tracked in the proof ledger. We show the number of paid calls, total spend, timestamps, and payment references so judges can clearly see the monetization flow in the product itself.

## 3:55 - 4:35

Show Gateway demo balance area in the lobby, if configured.

Voiceover:
When Circle Gateway demo mode is enabled, the buyer-side flow can be funded through the Gateway client and the advice endpoints can be paid through the real x402-compatible middleware path instead of our development fallback.

## 4:35 - 5:00

Return to lobby or branding view.

Voiceover:
WILDCARD is our view of a better Web3 game product: real gameplay, real payments, and AI that is monetized as a native mechanic instead of an afterthought.
