# Submission Checklist

- Public GitHub repo is accessible
- Web app is deployed and interactive
- Server deployment URL is stable
- Arc env vars are configured
- Circle x402 seller env vars are configured if using real Gateway mode
- Gateway demo private key is configured only on trusted server environments
- Cover image is exported as PNG or JPG
- Demo video is under 5 minutes
- PDF slide deck is exported
- Submission copy is pasted from `docs/submission/submission-copy.md`
- Video script is rehearsed from `docs/submission/video-script.md`
