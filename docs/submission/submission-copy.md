# WILDCARD Submission Copy

## Project Title

WILDCARD

## Short Description

1v1 poker duels on Arc with off-chain gameplay, magic actions, and gasless paid AI coaching via Circle x402 nanopayments.

## Long Description

WILDCARD is a fast 1v1 poker game built for Arc where the money layer stays credible and the gameplay stays responsive. Players deposit and lock USDC for a duel, while the poker engine, magic-card actions, and match state run off-chain on the server for low latency. This gives us a smoother player experience than putting every action on-chain, while still preserving an Arc-native financial flow for deposits, locked buy-ins, and settlement.

Our core product is not only the duel itself, but also paid AI assistance inside the match. Players can ask for a best move, a risk read, or magic timing advice. Those agent calls are monetized with x402-style nanopayments and are now wired for Circle Gateway flows, so the same product can evolve from a hackathon demo into a real usage-based gaming platform. We also added proof panels and payment history to make the monetization visible to judges and easy to demonstrate in the product.

The target users are competitive casual players, strategy learners, and game communities that want a product with stronger retention than a pure wallet demo. Our differentiation is the combination of Arc settlement, server-authoritative off-chain gameplay, fantasy presentation, and paid AI coaching as a native in-game service instead of an external chatbot bolted on afterward.
